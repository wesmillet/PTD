# Claude Code instructions for this project

Always read GAME_DESIGN.md in full at the start of every session. It is the
single source of truth for mechanics, content, tech stack, and the phase plan.

We work one phase at a time. Before writing code for a phase, write a short
plan in docs/plan-phase-N.md and wait for approval.

Sprites come from the PMDCollab SpriteCollab repo via sparse checkout only.
Never clone the whole repo. See the "Sprites and assets" section of
GAME_DESIGN.md for the exact commands and the sprite sheet format.
